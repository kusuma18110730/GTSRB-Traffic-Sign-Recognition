# 🚦 GTSRB Traffic Sign Recognition Using CNN

## 📌 Project Overview
This project uses a Convolutional Neural Network (CNN) to recognize and classify traffic signs using the German Traffic Sign Recognition Benchmark (GTSRB) dataset.

The model learns traffic sign patterns from images and predicts the corresponding traffic sign class.

## 🎯 Objectives
- Build a CNN-based traffic sign classification model.
- Train the model using the GTSRB dataset.
- Recognize and classify 43 different traffic sign categories.
- Evaluate the model's classification performance.

## 📊 Dataset
**Dataset:** German Traffic Sign Recognition Benchmark (GTSRB)

- Number of classes: 43
- Image dimensions: 32 × 32 × 3
- Training images: 31,367
- Testing images: 7,842

## 🛠️ Technologies Used
- Python
- TensorFlow
- Keras
- Convolutional Neural Network (CNN)
- Jupyter Notebook

## 🧠 Model
A Convolutional Neural Network (CNN) is used for image classification. The model learns important features from traffic sign images and classifies them into the appropriate categories.

## 📈 Results
**Reported Model Accuracy: 98.8%**

The trained model is saved as `traffic_sign_cnn.keras`.

## 📁 Project Files
- `MLproject.ipynb` – Jupyter Notebook containing the project code.
- `traffic_sign_cnn.keras` – Trained CNN model.

## ▶️ How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open `MLproject.ipynb` using Jupyter Notebook.
4. Make sure the GTSRB dataset is downloaded and available at the paths expected by the notebook.
5. Run the notebook cells to explore the project.
